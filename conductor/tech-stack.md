# Tech Stack

## Core Language
- **Python (3.8+):** The primary language for the library.

## Data Analysis & Statistics
- **Pandas:** Primary data structure for time-series financial data.
- **NumPy:** Efficient numerical computations.
- **SciPy:** Advanced statistical functions and distributions.

## Visualization
- **hvPlot:** High-level plotting API built on HoloViews and Bokeh for interactive visualizations. (Replacing Matplotlib and Seaborn)

## Data Acquisition
- **yfinance:** For downloading historical market data from Yahoo! Finance.

## Utilities
- **Tabulate:** For formatting tables in reports.
- **python-dateutil:** For robust date and time handling.
- **Packaging:** For version management and distribution.
