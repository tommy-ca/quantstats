# Product Guidelines

## Tone and Style
- **Developer-Centric:** Documentation should be practical, focusing on clear code examples and direct usage instructions.
- **Professional:** Maintain a standard of quality expected in financial software.
- **Concise:** Avoid unnecessary jargon while preserving technical accuracy.

## Visual Identity
- **Charts:** Use `seaborn` and `matplotlib` defaults that are clean and readable.
- **Reports:** HTML reports should be responsive and well-structured, suitable for professional presentation.

## Coding Standards
- **Idiomatic Python:** Leverage Pandas and NumPy efficiently (vectorization over loops).
- **Compatibility:** Ensure support for modern Python versions (3.8+) and key libraries.
- **Testing:** Maintain high test coverage for statistical accuracy.
