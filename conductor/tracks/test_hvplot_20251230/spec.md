# Spec: Unit tests and E2E tests for hvPlot migrations

## Overview
This track aims to establish a robust testing framework for hvPlot migration. The focus is specifically on ensuring that newly implemented interactive plots correctly integrate into final HTML reports generated by QuantStats.

## Functional Requirements
- **Unit Tests:** Verify individual plot functions return valid hvPlot/HoloViews objects when provided with live market data.
- **E2E Tests:** Generate full HTML reports using live data and verify output.
- **DOM Verification:** E2E tests must parse generated HTML and confirm the presence of:
    - Bokeh-specific `<div>` elements for plot containers.
    - Necessary `<script>` tags for Bokeh and HoloViews runtimes.
    - JSON payloads containing plot data/configuration.

## Non-Functional Requirements
- **Reliability:** Tests must handle potential network issues when fetching live data via `yfinance`.
- **Maintainability:** Use standard Python testing libraries (e.g., `pytest`, `beautifulsoup4` for DOM parsing).
- **Performance:** Validate that hvPlot generation time and memory usage are within acceptable thresholds compared to matplotlib.

## Acceptance Criteria
- [x] Test suite successfully fetches live data for a sample ticker (e.g., "AAPL").
- [x] Tests confirm that `qs.reports.html()` produces a file containing valid interactive plot markers.
- [x] No regression in report generation for standard metrics.
- [ ] Performance benchmarks completed with generation time <110% of matplotlib.
- [ ] Large dataset handling validated (10M+ data points).
- [ ] Edge case scenarios tested and documented.
- [ ] Cross-backend consistency verified.

## Extended Scope (Phase 5+)

### Performance Testing
- **Large Datasets:** Test hvPlot with 10M+ data points to identify performance bottlenecks.
- **Memory Profiling:** Compare memory usage between matplotlib and hvPlot backends.
- **Report Generation Time:** Benchmark full HTML report generation times across different data sizes.

### Edge Case Testing
- **Data Quality:** Test handling of empty, NaN, and corrupted data.
- **Timezone Handling:** Validate mixed timezone scenarios and edge cases.
- **Backend Switching:** Test mid-session backend changes and state management.
- **Network Resilience:** Test yfinance failures, timeouts, and rate limiting.

### Cross-Backend Compatibility
- **Feature Parity:** Verify consistent functionality between matplotlib and hvPlot backends.
- **Error Handling:** Test graceful degradation when backends are unavailable.
- **Parameter Inheritance:** Validate backend-specific parameters work correctly.

### Real-World Integration
- **Market Diversity:** Test different sectors, asset classes, and geographic markets.
- **Timeframes:** Validate daily, weekly, monthly, and minute-level data.
- **Crisis Periods:** Test behavior during high volatility and market crashes.
- **Production Environments:** Cross-platform testing (Linux, macOS, Windows) with various Python versions.

## Out of Scope
- Visual regression testing (screenshot comparison).
- Automated performance optimization beyond threshold validation.
- User interface testing of browser-based reports.
