# Technical Specification: Markdown Output Support

## Overview

This technical specification defines the implementation details for adding markdown output support to the QuantStats library. The feature will generate comprehensive portfolio performance analysis reports in markdown format, providing an alternative to the existing HTML tearsheet reports.

## System Architecture

### Current Architecture Context

QuantStats uses a modular architecture with:
- **Report Generation**: `reports.py` with template-based HTML generation
- **Plotting System**: Backend abstraction (`_plotting/backend.py`) supporting matplotlib and hvPlot
- **Utilities**: Data processing and formatting functions
- **Template System**: HTML template with placeholder replacement

### New Architecture Components

```
quantstats/
├── reports.py              # Enhanced with markdown() function and shared helpers
├── report.html             # Existing HTML template
├── report.md               # New markdown template
├── __init__.py             # Export markdown function
└── _plotting/
    ├── backend.py          # Existing backend abstraction (reused)
    └── [no new files]      # Leverage existing infrastructure
```

## API Specification

### Core Function: `quantstats.markdown()`

```python
def markdown(
    returns,
    benchmark=None,
    rf=0.0,
    title="Strategy Tearsheet",
    output=None,
    compounded=True,
    periods_per_year=252,
    figfmt="png",
    template_path=None,
    match_dates=True,
    embed_images=True,
    **kwargs,
) -> Optional[str]:
```

#### Parameter Specification

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `returns` | pd.Series/pd.DataFrame | Required | Strategy returns data |
| `benchmark` | pd.Series/str/None | None | Benchmark for comparison |
| `rf` | float | 0.0 | Risk-free rate (decimal) |
| `title` | str | "Strategy Tearsheet" | Report title |
| `output` | str/None | None | Output file path |
| `compounded` | bool | True | Use compounded returns |
| `periods_per_year` | int | 252 | Trading periods per year |
| `figfmt` | str | "png" | Figure format (png/svg/jpg) |
| `template_path` | str/None | None | Custom template path |
| `match_dates` | bool | True | Align returns/benchmark dates |
| `embed_images` | bool | True | Base64 embed vs file links |
| `**kwargs` | dict | {} | Additional parameters |

#### Return Value

- **str**: Markdown content when `output=None`
- **None**: When saved to file or displayed in notebook

#### Exception Handling

```python
# ValueError conditions
if output is None and not _utils._in_notebook():
    raise ValueError("`output` must be specified when not in notebook")

# FileNotFoundError conditions  
if template_path is not None and not Path(template_path).exists():
    raise FileNotFoundError(f"Template file not found: {template_path}")
```

## Helper Functions Specification

These helpers follow the patterns established by `_html_table` and `_embed_figure` to ensure consistent behavior across output formats.

### Table Formatting: `_markdown_table()`

```python
def _markdown_table(obj, showindex="default") -> str:
    """
    Convert DataFrame to markdown table format.
    
    Integrated with the same tabulate logic used in _html_table().
    """
    return _tabulate(
        obj, 
        headers="keys", 
        tablefmt="pipe", 
        floatfmt=".2f", 
        showindex=showindex
    )
```

## Data Flow Specification

### Processing Pipeline

```
Input Data (returns, benchmark)
    ↓
Data Preparation (_prepare_returns, _match_dates)
    ↓
Metrics Calculation (metrics())
    ↓
Plot Generation (plots.* functions)
    ↓
Template Processing (report.md)
    ↓
Figure Embedding (_embed_markdown_figure)
    ↓
Table Formatting (_markdown_table)
    ↓
Output Generation (markdown string/file)
```

### Detailed Flow

1. **Input Validation**
   - Check returns data type and format
   - Validate benchmark compatibility
   - Verify template path if provided

2. **Data Processing**
   - Clean returns data (remove NaN, align dates)
   - Prepare benchmark data if provided
   - Calculate trading periods

3. **Metrics Generation**
   - Call existing `metrics()` function
   - Format results for markdown table
   - Handle multi-column scenarios

4. **Plot Generation**
   - Generate all required plots using existing backend
   - Convert to appropriate format for markdown
   - Handle backend-specific requirements

5. **Template Processing**
   - Load markdown template
   - Replace placeholders with generated content
   - Handle conditional sections (benchmark, etc.)

6. **Output Handling**
   - Return string or save to file
   - Handle notebook display
   - Manage file permissions and paths

## Backend Integration Specification

### Matplotlib Backend Integration

```python
# Figure generation for matplotlib
if _plotting_backend.is_matplotlib():
    # Use existing plot generation
    fig = _plots.cumulative_returns(returns, benchmark, **kwargs)
    
    # Convert to StringIO for embedding
    img_data = StringIO()
    fig.savefig(img_data, format=figfmt, bbox_inches='tight')
    
    # Embed in markdown
    markdown_img = _embed_markdown_figure(img_data, figfmt, embed_images)
```

### hvPlot Backend Integration

```python
# Figure generation for hvPlot
if _plotting_backend.is_hvplot():
    # Generate interactive plot
    plot = _plots.cumulative_returns(returns, benchmark, backend='hvplot')
    
    # Export static version for markdown
    if embed_images:
        # Save to temporary buffer
        img_data = _hvplot_backend.export_static(plot, fmt=figfmt)
        markdown_img = _embed_markdown_figure(img_data, figfmt, True)
    else:
        # Fallback message
        markdown_img = "*Interactive chart not supported in markdown format*"
```

## Error Handling Specification

### Input Validation Errors

```python
# Returns data validation
if returns is None or len(returns) == 0:
    raise ValueError("Returns data cannot be empty")

# Data type validation
if not isinstance(returns, (pd.Series, pd.DataFrame)):
    raise TypeError("Returns must be pandas Series or DataFrame")

# Benchmark validation
if benchmark is not None and not isinstance(benchmark, (pd.Series, str, pd.DataFrame)):
    raise TypeError("Benchmark must be pandas Series, string ticker, or DataFrame")
```

### Template Processing Errors

```python
# Template file validation
if template_path is not None and not Path(template_path).exists():
    raise FileNotFoundError(f"Template file not found: {template_path}")

# Template content validation
if not any(placeholder in tpl for placeholder in ['{{title}}', '{{metrics}}']):
    raise ValueError("Invalid template: missing required placeholders")
```

### Figure Generation Errors

```python
# Backend availability
if not _plotting_backend.is_matplotlib() and not _plotting_backend.is_hvplot():
    raise RuntimeError("No plotting backend available")

# Figure format validation
if figfmt not in ['png', 'svg', 'jpg', 'jpeg']:
    raise ValueError(f"Unsupported figure format: {figfmt}")
```

## Performance Specifications

### Memory Usage

- **Base64 Embedding**: ~33% increase in memory usage due to encoding
- **File Reference**: Minimal memory overhead
- **Large Datasets**: Stream processing for figures >10MB

### Processing Time

- **Target**: <110% of HTML generation time
- **Figure Export**: Dominant factor in processing time
- **Template Processing**: <5% of total time

### File Size

- **Base64 Embedded**: ~1.33x original figure size
- **File Reference**: Base markdown + figure files
- **Compression**: SVG typically smaller than PNG for charts

## Security Considerations

### Path Traversal Prevention

```python
# Secure template path handling
template_path = Path(template_path).resolve()
if not str(template_path).startswith(str(Path(__file__).parent)):
    raise ValueError("Template path must be within quantstats directory")
```

### File Output Security

```python
# Secure file output handling
if output is not None:
    output_path = Path(output).resolve()
    # Validate parent directory exists and is writable
    if not output_path.parent.exists():
        raise FileNotFoundError(f"Output directory does not exist: {output_path.parent}")
```

### Base64 Encoding Safety

```python
# Safe base64 encoding
def safe_base64_encode(data):
    try:
        return _b64encode(data).decode('utf-8')
    except Exception as e:
        raise ValueError(f"Failed to encode figure data: {e}")
```
